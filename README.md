## 4. Функциональные тест-кейсы.

### TC-SEARCH-001 - Поиск по точному названию товара
- **Приоритет:** High
- **Предусловие:** Пользователь на главной странице, поисковая строка доступна
- **Шаги:**
  1. Ввести в поиск точное название: `Sony A7 III`
  2. Нажать Enter или кнопку поиска
- **Ожидаемый результат:** В выдаче отображается карточка «Sony A7 III». Результаты отсортированы по релевантности.
- **Статус:** PASS

### TC-SEARCH-002 - Поиск по точному названию товара
- **Приоритет:** High
- **Предусловие:** Пользователь на главной странице, поисковая строка доступна
- **Шаги:**
  1. Ввести в поиск точное название: `sony a7 3`
  2. Нажать Enter или кнопку поиска
- **Ожидаемый результат:** В выдаче отображается карточка `Sony A7 III`. Результаты отсортированы по релевантности.
- **Статус:** FAIL
- **Комментарий:** Камера отображается в поиске, однако на первом месте стоит камера Sony A7 IV, что для нашего результата нерелевантно.

### TC-SEARCH-003 - Поиск по частичному совпадению
**Предусловие:** Пользователь на главной странице, поисковая строка доступна
- **Приоритет:** High
- **Шаги:**
  1. Ввести в поисковую строку часть названия, например, `Sony`
  2. Нажать Enter.
- **Ожидаемый результат:** В результатах отображаются все товары, содержащие «Sony» в названии или описании. Если таких товаров нет, показывается сообщение «Ничего не найдено» с предложением изменить запрос.
- **Статус:** PASS

- ### TC-SEARCH-004 - Поиск по категории оборудования
- **Приоритет:** Medium
- **Предусловие:** Пользователь на главной странице, поисковая строка доступна
- **Шаги:**
  1. Ввести `свет`
  2. Нажать Enter
- **Ожидаемый результат:** Выдача содержит осветительное оборудование (софтбоксы, стойки, лампы).
- **Статус:** PASS

### TC-SEARCH-005 - Поиск с фильтрами
- **Приоритет:** High
- **Предусловие:** Выполнен поиск по запросу `камера`
- **Шаги:**
  1. Установить фильтр по цене (1000–3000 ₽/сутки)
  2. Выбрать бренд `Canon`
  3. Применить фильтры
- **Ожидаемый результат:** Результаты поиска обновляются, отображаются только товары, соответствующие выбранным фильтрам. Количество результатов уменьшается по сравнению с исходным.
- **Статус:** FAIL
- **Комментарий:** Фильтры при поиске товара из поисковой строки недоступны.

### TC-SEARCH-006 - Пустой запрос
- **Приоритет:** Medium
- **Шаги:**
  1. Оставить строку пустой
  2. Нажать Enter
- **Ожидаемый результат:** Поиск не выполняется. Показывается подсказка «Введите поисковый запрос» или строка остаётся в фокусе. Страница не перезагружается.
- **Статус:** PASS
- **Комментарий:** подсказка не выводится, страница отображается с пустым результатом.

- ### TC-SEARCH-007 - Несуществующий товар
- **Приоритет:** High
- **Шаги:**
  1. Ввести `дракон`
  2. Нажать Enter
- **Ожидаемый результат:** Страница с сообщением «По вашему запросу ничего не найдено» и блоком популярных товаров.
- **Статус:** PASS
- **Комментарий:** подсказки не выводятся, страница отображается с пустым результатом.

### TC-SEARCH-008 - Специальные символы
- **Приоритет:** Medium
- **Шаги:**
  1. Ввести `!@#$%^&*()_+`
  2. Нажать Enter
- **Ожидаемый результат:** Корректная обработка (пустой результат или сообщение о некорректном запросе). Ошибок 500 нет, страница не зависает.
- **Статус:** PASS
- **Комментарий:** страница отображается с пустым результатом.

### TC-SEARCH-009 - Автодополнение
- **Приоритет:** Medium
- **Шаги:**
  1. Начать вводить `объ`
  2. Не нажимая Enter, посмотреть выпадающий список
- **Ожидаемый результат:** Появляется список подсказок («объектив», «объектив Canon» и т.д.).
- **Статус:** PASS
- **Комментарий:** при вводе `объ` также выводятся дым-машины, так как у них имеется свойство объем бака. Для нашего поиска это нерелевантный результат. Однако если вводить слово дальше, будут предложены объективы.

### TC-SEARCH-010 - Проверка сортировки результатов по цене (возрастание/убывание)
- **Приоритет:** High
- **Предусловие:** Пользователь выбрал категорию оборудования слева, затем выбрал категорию товара (прим. камеры > камеры Sony)
- **Шаги:**
1. Выбрать в фильтре слева "подешевле".
2. Затем выбрать в фильтре слева "подороже"
- **Ожидаемый результат:** Список товаров был отсортирован сначала по возрастающей цене, затем по убывающей цене
- **Статус:** PASS

### TC-SEARCH-011 - Переход на вторую страницу результатов поиска
- **Приоритет:** High
- **Предусловие:** Пользователь выбрал категорию оборудования слева, затем выбрал категорию товара (прим. камеры > камеры Sony)
- **Шаги:**
"1. Промотать страницу с товарами вниз.
2. Нажать "страница 2" или "следующая"
- **Ожидаемый результат:** Отображается вторая страница с товарами в выбранной категории, доступны следующие и предыдущие страницы
- **Статус:** PASS

- ## 6. Нефункциональные тест-кейсы.

### TC-PERF-001 - Нагрузка: 10 последовательных запросов
- **Приоритет:** Medium
- **Шаги:**
  1. Подряд ввести 10 разных запросов с интервалом ~2 сек
  2. Замерить среднее время отклика и потребление памяти
- **Ожидаемый результат:** Среднее время отклика не растёт. Утечек памяти нет. Интерфейс не «тормозит».
- **Статус:** PASS
- **Комментарий:** Альтернатива запуск коллекции GET запросов через POSTMAN с интервалом в 2000 мс и последующей генерацией отчета в newman. Позже прикреплю отчет newman.
- **Приложение:** [отчет newman из Postman collection runner](https://disk.yandex.ru/d/35K1bTilg9brnQ)

### TC-PERF-002 - Время отклика поиска
- **Приоритет:** High
- **Шаги:**
  1. Открыть DevTools → вкладка Network
  2. Ввести запрос "камера"
  3. Замерить время от ввода до отображения результатов
- **Ожидаемый результат:** Время отклика ≤ 2 сек.
- **Фактический результат:** *2,99с*
- **Статус:** PASS
- **Комментарий:** ФР в пределах нормы 2-3 секунды.

### TC-PERF-003 - Поиск при большом количестве результатов
- **Приоритет:** Medium
- **Шаги:**
  1. Ввести широкий запрос `камера`
  2. Проверить, как отображается выдача при 100+ товарах
- **Ожидаемый результат:** Страница загружается ~ 2 сек, скролл плавный, пагинация отсутствует.
- **Статус:** PASS

### TC-PERF-004 - Мобильная производительность
- **Приоритет:** High
- **Шаги:**
  1. В Chrome DevTools включить throttling → Fast 3G / Slow 4G
  2. Ввести запрос `штатив`
- **Ожидаемый результат:** Результаты появляются ~ 4 сек на 4G.
- **Статус:** PASS

### TC-PERF-005 - Поиск с запросом 500+ символов
- **Приоритет:** Low
- **Шаги:**
  1. Ввести 500+ символов в поисковую строку
  2. Нажать Enter
- **Ожидаемый результат:** Система либо обрезает запрос до лимита, либо показывает «Превышен лимит символов». Без ошибок и зависаний.
- **Статус:** FAIL
- - **Комментарий:** на десктопе страница зависает в течении 25-27 секунд. Нет лимита символов для поисковых запросов.
